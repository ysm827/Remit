# Community code of conduct

Remit welcomes contributors with different backgrounds and levels of
experience. Participation in project spaces requires respectful, constructive
behavior.

Expected behavior includes:

- discussing ideas and code without attacking people;
- accepting technical feedback in good faith;
- respecting privacy, attribution, licenses, and consent;
- making room for questions and different communication styles;
- focusing disagreements on evidence and project outcomes.

Harassment, discrimination, threats, sexualized attention, deliberate
misattribution, doxxing, or sustained disruption are not acceptable.

Repository maintainers may edit or remove contributions, comments, or other
participation that violates these expectations and may temporarily or
permanently restrict participation. Report conduct concerns privately to the
repository owner. Reports will be handled as confidentially as practical.

This code applies in repository spaces and when someone is publicly
representing the Remit project.
