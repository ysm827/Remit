# 论文生成与排版检查

中文数模论文默认按以下流程生成。正文和章节修订仍由 WriterAgent 完成，排版器只处理结构、字体、图幅和公式换行。

## 默认篇幅

- 摘要正文目标 750–1100 字符；关键方法和关键数值结果加粗，关键词整行加粗。
- 编译后实际检查首页内容位置，目标约为页面高度的 80%，接受范围为 72%–90%。不会靠增加空白、缩小字号或截断正文达标。
- 问题重述目标 200–550 字符，问题分析 250–750 字符，假设 150–450 字符。前三项允许 10% 的小幅上浮，避免标点和单位导致整篇写作中断。
- 总符号表至多 18 个数据行，局部符号在对应公式旁解释。篇幅规则不替代科学证据要求，也不会删除计算结果和局限。
- 英文竞赛论文不套用中文字符预算。

## 生成与检查

1. 逐章核对正文、证据、数值与插图。失败反馈合并返回，章节有一次修订机会；已通过章节保存在检查点中。
2. 每个章节通过后更新部分草稿，界面明确显示仍在写作。用户编辑过的源码不会被自动覆盖。
3. 中文排版器保留完整摘要与强调内容，首段缩进两个正文字符；将长公式中的独立等式分行，把简短符号表保持在同一页。
4. 插图保持纵横比，统一采用正文宽度的 68%，高度上限为正文高度的 42%；特别高的图为避免越页仍会缩小。图题与图绑定，短数值表按内容分配列宽，所有列与表头居中；名称和单位优先保持一行，不强制拆分单位。图表允许在页顶或页底浮动，避免强制原地放置造成大片空白。最终仍需检查图内标签是否够大。
5. 编译后检查摘要占页、首段实际缩进、跨页关键词、缺字、明显溢出和图片占幅。中文正文中间页连续留白超过版心高度的 23% 会报告问题（摘要页及最后一页除外）。摘要版式不合格会将实际 PDF 反馈交给 WriterAgent 再修订一次。超出修订次数仍保留草稿并报告问题，不把编译成功当作质量验收。

## 图文证据

独立论文写作入口会把该章节的实际 CSV/JSON 证据摘录交给 WriterAgent，优先提供与插图相关的 CSV。读取前校验快照路径和 SHA-256，单文件至多 6000 字符、每章至多 24000 字符；截断与未附文件明确标记，CSV 不截断数据行。论文手必须区分曲线分组与单位，不能沿用与明细冲突的旧汇总，也不能从不完整摘录推断全体场景。该措施改善证据输入，不等于自动证明所有科学结论正确。

## 中文图表

Python 本地和云端解释器在实际排版文字时核对字体字符覆盖，即使 seaborn 重设绘图风格，也会重新选择能显示中文的字体。没有合适字体时返回明确错误，不静默导出方框文字。MATLAB 初始化时选择已安装的中文字体；缺失时发出提示。

安装包和源码环境的字体来源可能不同。可使用 Fandol、Noto Sans CJK 等兼容字体；不在公开仓库分发用户机器上的商业字体。自动字体检查不能发现所有位图中的乱码、标注遮挡或科学错误，最终仍需逐图检查。

## 已有论文的修订

同一证据版本下，`POST /api/writing/{task_id}/generate?revise_style=true` 会另存新稿，复用求解章节并重写五个前置章节。复用内容仍执行当前校验，不重新求解。

已有图的显示修订可以通过论文目录中的 `figure_overrides.json` 登记。必须绑定原证据版本，并同时记录原图与新图的 SHA-256；路径越界或文件变化会拒绝使用。原图和科学输出保持不变，修订者需另行核对重绘图的数值。

## 验收边界

自动检查通过表示已通过当前可测的排版规则，不代表模型正确、数值口径一致或论文已达到竞赛获奖水平。用户仍需验收科学结论、引用与最终视觉效果。

## 图表取舍与符号规范

可用图片是候选证据，不再强制全插入，也不要求每幅图后至少三行说明。WriterAgent 根据论证保留具有独特贡献的图，在正文中自然引用、比较和讨论局限。未采用的图须以隐藏记录说明替代证据位置，系统单独保存到章节检查点的 `omitted_images`；不会删除原图。校验拒绝无理由缺图、未知图片的取舍记录、同图既插入又舍弃，以及省略全部候选图。记录检查不能代替科学审阅，负结果不可因精简被隐藏。

变量用数学斜体，向量和矩阵采用 `\bm` 加粗斜体；已有数学环境中的 `\mathbf`、`\boldsymbol` 会统一转为 `\bm`。单位、函数名和说明性下标保留正体。论文手须保持各章符号定义与字体一致，默认集合采用大写斜体，不能因字体相似合并不同数学对象。代码片段及普通正文中的命令不作向量替换。

当前自动检查侧重结构、证据引用和可测版式；不能保证任意模型输出、任意图片都无需人工复核。安装包需重新构建后才包含这些修复，仅同步源代码不会更新已经安装的旧版本。

中文正文采用按素材文件引用图片的标记（`@fig:文件名.png@`），排版器在确定选图和编号后替换为实际图号；引用不存在的图片会中止发布。正文中间页如有多张图片而几乎没有论证文字，会报告图文分离。图的浮动优先与文字同页，不主动生成纯图片页；极端内容仍须根据检查反馈调整。
