# Remit 2.0.1

Remit 2.0 的首个修复版本，包含 [2.0.0 的全部升级](2.0.0.md)。

## 修复

- 修复本地 Python 内核导出图片时调用不存在的 `Figure.findall` 方法的问题，改用 Matplotlib 的 `findobj`。
- 增加真实 Jupyter 内核回归：经过产品的字体初始化后，实际导出 PNG 与 PDF，并检查上标转换和已有数学公式。
- 修复 Linux CI 的无显示器桌面测试环境。

## 下载与验证

Windows x64、macOS Apple Silicon 与 macOS Intel 的未签名安装包，只有在各自原生环境完成运行时、安装和迁移路径验证后，才会上传到本版本。没有 `.exe` / `.dmg` 附件时，安装包尚未交付。

源码与 Docker 镜像可独立发布。没有签名或公证凭据，安装包可能受到系统发布者验证提示；模型服务仍需用户自行配置，MATLAB 需要自己的授权。自动测试不等同于所有竞赛题都能免审交付。

旧版源码、品牌图片、Star History 和群聊码继续保留。原 2.0.0 标签保持不变。
