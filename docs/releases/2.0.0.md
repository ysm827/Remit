# Remit 2.0.0

2026-09-30

Remit 2.0 将新版数模工作台整合回原仓库。原有商标、群聊二维码、Star History 与 Git 提交历史保留。

## 主要变化

- 团团、灵灵、点点、墨墨分别承担协调、建模、代码与论文角色。对话展示当前阶段、关键结果与异常，详细活动按需展开。
- 探索实验按小问执行，复用已通过校验的检查点；改进模型响应恢复、执行故障反馈和继续任务的路由。
- 建模成果同步到独立论文工作区，支持章节续写、手工编辑保护、LaTeX 源码与 PDF 预览。
- 论文根据证据贡献选图并记录取舍，统一数学斜体、向量加粗斜体、居中三线表、图幅和真实图号，检查摘要占页、缩进与明显留白。
- 提供 Windows x64、macOS arm64 / x64 原生安装包构建与安装后验证流程。

## 下载与依赖

本 Release 的源码压缩包可直接下载。安装器仅在三个平台的构建和安装验证通过后上传；若尚未出现 `.exe` / `.dmg` 附件，表示这批安装包尚未交付，请使用源码部署或等待构建结果。

桌面包包含 Python、常用科学计算库、Redis、Pandoc、XeLaTeX 和中文字体。模型服务地址、模型名称与密钥需自行配置；MATLAB 及其工具箱需要用户自行安装并持有许可证。包未做 Windows 发布者签名或 Apple 公证。

源码部署与桌面包的依赖范围不同，详见 [安装说明](https://github.com/zhou2030109-glitch/Remit/blob/main/docs/desktop-distribution.md)。

## 验证范围

本次源码迁移已通过 533 项后端测试（另有 1 项跳过）、73 项前端测试及前端生产构建。论文规则也已实际验证一篇中文论文的生成、编译与排版。不同题型、模型供应商、图片和电脑环境仍可能产生问题；自动检查通过不能代替科学结论与最终交付验收。当前版本的自动构建结果以本仓库 Actions 和随安装包提供的验证报告为准。

公开版本不包含开发者密钥、个人设置、真实赛题附件、试跑论文或运行记录。
