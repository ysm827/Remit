# 使用流程

1. 在模型连接设置中配置协调手、建模手、代码手和论文手。
2. 新建项目并选择赛事；添加题面与数据附件，文件夹按原目录结构导入。
3. 协调手预读题意并询问缺失信息。核对计划后确认执行。
4. 工作区展示当前阶段、关键进展与待核验事项；详细调用记录按需展开。
5. 建模和计算阶段检查附件读取、方案、计算产物与验证报告。失败时保留已有文件，从适用检查点恢复。
6. 用户审核方案和成果。完成标记、代码执行成功或有效 JSON 都不能替代科学结果验收。
7. 将建模证据交接给论文工作区，编辑 LaTeX、检查 PDF 并导出。

聊天问进度与修改任务分别处理；普通提问不应中断计算。通过调整任务入口修改要求时，先检查受影响的执行范围。

参考 [安装](../README.md)、[赛事适配](competition-adapters.md)、[论文工作区](writing-workspace.md) 与 [故障和可靠性](reliability.md)。
